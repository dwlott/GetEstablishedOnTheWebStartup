# High Altitude Theme Method (starter pointer)

**High Altitude** is the product name for the StudioPress **Altitude**-based
theme approach used on commissioned sites. This starter does **not** ship
`Capabilities/AltitudeProOverlay/` or full High Altitude CSS recipes.

## New-site recipe

1. Choose **Dark** or **Light** High Altitude base.
2. Copy the theme folder into the project’s `wp-content/themes/`.
3. Adjust brand colors, header, and logo only — do not restyle the whole cascade in chat.
4. After adopt, **promote** `AltitudeProOverlay` onto the **project repo** from a
   proven commission pattern (DansRepairService Dark; US1Movers Light-direction).

## Where the Cap lives

| Repo | Role |
| --- | --- |
| **This starter** | Method pointer only — Cap intentionally absent |
| **DansRepairService** | Latest successful **Dark** consumer (live Bluehost) |
| **US1Movers** | **Light-direction** consumer |
| **MoverCalcsWeb** | Owns Dark CSS + forum (when available) |

## Starter guardrail

Do not copy customer theme CSS or AltitudeProOverlay into
GetEstablishedOnTheWebStartup packaging. After `Copy-StartupToProject`, port the
Cap onto the new project when the owner chooses High Altitude.
